# Legacy tools

These tools are kept online for first-generation OpenCollar devices and old Edge firmware. They are not maintained for current releases.

{{ tool_cards(status=['legacy']) }}

- **Smart Parks Toolset** ([toolset.smartparks.org](https://toolset.smartparks.org/)): a battery calculator, a payload decoder app and an encoder app. Its repository holds the first-generation decoders and encoders and the ChirpStack v4 Edge decoders up to firmware 6.5.0.
- **Smart Parks Connect Web**: a Go and Vue application that composes settings and command downlinks for a ChirpStack v3 server or RockBLOCK. It uses settings templates for firmware 2.10, 2.15 and 3.2 and has not been updated since 2023.

For current devices use the [BLE web app](configure.md) and the [raw logs decoder](decode-logs.md).
